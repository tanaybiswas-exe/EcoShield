নাসা ডেটা সোর্স ও বৈজ্ঞানিক মেথডোলজি

1. NASA ECOSTRESS (ISS) Thermal Radiance

ECOsystem Spaceborne Thermal Radiometer Experiment on Space Station delivers 70m Land Surface Temperature and Emissivity (LSTE) Collection 2 data. We utilize the TIR 5-band split-window algorithm to resolve intra-urban boundary layer temperature variations across high-density megacity grids.

2. Landsat 9 (OLI-2 / TIRS-2) Downscaling

Spectral decomposition derived from Band 4 (Red), Band 5 (Near Infrared - NIR), and Band 6 (Short-Wave Infrared 1 - SWIR1):

• NDVI = (Band 5 - Band 4) / (Band 5 + Band 4) [Fractional Vegetation Cover]
• NDBI = (Band 6 - Band 5) / (Band 6 + Band 5) [Impervious Surface Density]

3. NOAA Steadman Heat Index Implementation

Calculated via Rothfusz polynomial regression with dry-bulb ambient temperature and relative humidity.

4. OpenAQ Ground Validation API

In-situ continuous particulate calibration pulled via OpenAQ v3 API from reference grade US Embassy Dhaka sensors.
